# Glosarium & Disambiguasi BGN/MBG/SIPGN

## Lembaga & program

| Istilah | Arti |
|---|---|
| **BGN** | Badan Gizi Nasional — lembaga di bawah Presiden, penyelenggara MBG (Perpres 83/2024) |
| **MBG** | Makan Bergizi Gratis — program pemberian makan bergizi (makan pagi ATAU siang) |
| **KPPG** | Kantor Pelayanan Pemenuhan Gizi — UPT BGN tingkat wilayah (BUKAN dapur) |
| **SPPG** | Satuan Pelayanan Pemenuhan Gizi — unit dapur/pelayanan tingkat kecamatan |
| **Ka.SPPG** | Kepala SPPG (ditetapkan BGN) |
| **SPPI** | Sarjana Penggerak Pembangunan Indonesia — program penempatan sarjana (a.l. calon Ka.SPPG) |
| **Penerima Bantuan / Yayasan / Mitra** | Badan hukum yang bekerja sama dgn BGN & menerima Bantuan Pemerintah utk fasilitas SPPG |
| **PM (Penerima Manfaat)** | Orang yang menerima makanan (peserta didik, pendidik, tendik, 3B) |
| **3B** | **Ibu hamil (bumil), ibu menyusui (busui), balita ≥6 bln–<5 thn** (Juknis 2026). ⚠️ JANGAN rancu dgn slogan pangan "B2SA" (Beragam Bergizi Seimbang Aman — istilah Bapanas) atau "Bergizi/Beragam/Berimbang" |
| **Deputi BGN** | DIALUR (Penyediaan & Penyaluran), PROKERMA (Promosi & Kerja Sama), SISTAKOL (Sistem & Tata Kelola), TAUWAS (Pemantauan & Pengawasan) |
| **Kreg/Korwil/Korcam** | Koordinator region/wilayah/kecamatan (struktur koordinasi lapangan) |
| **Generasi Emas 2045** | Visi jangka panjang program |

## Tata kelola & keuangan

| Istilah | Arti |
|---|---|
| **Juknis** | Petunjuk Teknis — utk TA 2026: Kepka BGN 401.1/2025 |
| **Banper** | Bantuan Pemerintah (skema pendanaan MBG) |
| **PKS / BAST** | Perjanjian Kerja Sama / Berita Acara Serah Terima |
| **VA SPPG** | Virtual Account rekening SPPG (5 bank Himbara; auto top-up ±10 hari) |
| **HET** | Harga Eceran Tertinggi — acuan at cost bahan baku (terbitan pemda) |
| **At cost** | Pertanggungjawaban sesuai biaya riil |
| **Insentif fasilitas** | Rp6 jt/hari ke penyedia fasilitas SPPG (availability-based) |
| **PPK / KPA / PPSPM** | Pejabat Pembuat Komitmen / Kuasa Pengguna Anggaran / Pejabat Penandatangan SPM |
| **DIPA** | Daftar Isian Pelaksanaan Anggaran |
| **Suspend / Suspend Mayor** | Penghentian sementara SPPG; kategori mayor tak menerima insentif |
| **KM (Kejadian Menonjol)** | Insiden luar biasa MBG (utamanya dugaan keracunan massal) |
| **SLHS** | Sertifikat Laik Higiene Sanitasi |
| **Organoleptik** | Uji sensorik makanan (warna, aroma, rasa, tekstur) |
| **Akreditasi SPPG** | Peringkat A (Excellent) / B (Very Good) / C (Good) — mulai 2026 |
| **AKG** | Angka Kecukupan Gizi (Permenkes 28/2019) |
| **PPPK** | Status pegawai SPPG per Perpres 115/2025 |

## Digital & data

| Istilah | Arti |
|---|---|
| **SIPGN** | Sistem Informasi Pemenuhan Gizi Nasional — platform digital MBG (Peruri × Pusdatin) |
| **SMO** | Sistem Manajemen Operasional = **dialur.bgn.go.id** |
| **Pormit** | Portal Mitra = **mitra.bgn.go.id** (pendaftaran tutup per Juni 2026) |
| **Tauwas Care** | Platform pengawasan internal (checklist dapur oleh Ka.SPPG) |
| **SAGI 127** | Sentra Aduan Gizi Indonesia — call center publik 127 |
| **Jaga Dapur MBG** | Aplikasi pengawasan bersama Kejagung |
| **MPM** | (Aplikasi) Manajemen Penerima Manfaat — front-end MDM PM |
| **MDM** | Master Data Management (Individu, KPM, SPPG) |
| **KPM** | **Kelompok** Penerima Manfaat (kode = NPSN utk sekolah). ⚠️ Di program bansos lain "KPM" = Keluarga Penerima Manfaat — di konteks BGN selalu Kelompok |
| **Entitlement** | Model kontrol pemadanan hak per individu dalam satu KPM |
| **PEM** | Kode domain Penerima Manfaat (mis. PEM-CR-IMPL-PLAN-001) |
| **PIP / PMA / SDK / PKS-MR** | Kode submodul di nomor dokumen Peruri (Pusat Informasi Program / Penerima Manfaat / Sistem-Tata Kelola / Manajemen Kerjasama) |
| **CR Gateway** | Alur change-request master data antar data product (data mesh) |
| **G-01 / G-03** | Data Vocabulary / Data Dictionary (dokumen governance per data product) |
| **SCM / ERP / POP / HRIS / AMS / LMS / KinOps / FinDash** | Aplikasi fungsional SIPGN (pengadaan / produksi / titik layanan / kepegawaian / aset / pembelajaran / dashboard ops / keuangan) |
| **PVR** | Palm Vein Reader — absensi biometrik telapak tangan |
| **XPASS** | Instansiasi SSO (Keycloak) Peruri utk SIPGN |
| **Kong** | API gateway SIPGN |
| **Dapodik / EMIS** | Data pokok pendidikan Kemendikdasmen / Kemenag |
| **NPSN / NISN / NIK** | Nomor pokok sekolah / induk siswa / induk kependudukan |
| **MonSAKTI** | Sistem Kemenkeu — sumber data pagu & realisasi anggaran |
| **Bapanas** | Badan Pangan Nasional (referensi harga pangan) |
| **SATUSEHAT** | Platform interoperabilitas data kesehatan Kemenkes (rencana pertukaran data) |
| **TW** | Tim/auditor kualitas eksternal proyek SIPGN (konteks audit dokumen) |
| **UIN** | Unique Identification Number PM (10 digit, checksum Verhoeff) — desain internal |

## Yang BUKAN domain skill ini

PKH, BPNT/sembako, BLT, KIP/PIP (bansos Kemensos/Kemendikbud — bukan BGN); SAKTI/SIMPONI (sistem keuangan K/L lain; MonSAKTI hanya sebagai sumber data); program makan siang negara lain.
