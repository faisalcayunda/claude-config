## 12. Gate Review Checklist

### Gate 1: Discovery → Definition
- [ ] Problem validated with evidence (≥5 user interviews or survey N≥50)
- [ ] Market opportunity confirmed (TAM/SAM/SOM)
- [ ] Personas research-validated
- [ ] Sponsor approval to proceed

### Gate 2: Definition → Build
- [ ] BRD/SRS approved by stakeholders
- [ ] Architecture (system design + ADR) reviewed
- [ ] Tracking plan defined
- [ ] Sprint plan created

### Gate 3: Build → Launch
- [ ] UAT passed
- [ ] Usability test completed (SUS ≥68)
- [ ] Accessibility audit passed (WCAG 2.1 AA)
- [ ] Performance benchmark met
- [ ] Runbook documented

### Gate 4: Launch → Optimize
- [ ] Launch metrics captured (health scorecard)
- [ ] Win/loss tracking active
- [ ] Retrospective completed
- [ ] Next cycle priorities defined
