## Objection Handling

| Keberatan | Respon Strategis |
| :--- | :--- |
| **"Kenapa tidak pakai open-source (CKAN/DKAN)?"** | CKAN/DKAN adalah komponen katalog data yang baik, namun hanya mencakup 1 dari 7 komponen ekosistem data. IDEAS menyediakan ekosistem terintegrasi (Portal, Katalog, Dashboard, Geospasial, Pipeline, API Gateway, Governance Framework) untuk menghindari "portal tanpa ekosistem". |
| **"Kenapa tidak pakai konsultan Big 4?"** | Big 4 unggul dalam konsultasi enterprise global, namun untuk manajemen data di Indonesia: (1) Biaya 3-5x lebih tinggi, (2) Framework generik, kurang spesifik data management, (3) Pemahaman regulasi lokal (SPBE, SDI) tidak sedalam IDEAS. |
| **"Kami sudah punya tim IT internal."** | IDEAS tidak menggantikan, melainkan memberdayakan tim internal melalui: (1) Transfer pengetahuan dan sertifikasi (CDMP/BNSP), (2) Framework dan SOP untuk dijalankan tim internal, (3) DGO-as-a-Service sebagai pendampingan. |
| **"Anggaran terbatas."** | Kami menawarkan pendekatan modular: (1) Mulai dari asesmen (S1.3), (2) Implementasi bertahap sesuai siklus anggaran, (3) Opsi DGO-as-a-Service untuk mengurangi CAPEX, (4) Pembelian tools via INAPROC e-Katalog mulai dari Rp 155K. |
| **"Proses pengadaan lama."** | IDEAS terdaftar di **INAPROC e-Katalog v6**. Instansi pemerintah dapat langsung membeli melalui **e-Purchasing** tanpa tender. Sebagai penyedia **UMKK**, kami juga mendapat preferensi pengadaan. |
| **"Ada yang lebih murah di INAPROC."** | Harga terendah tidak menjamin kualitas. Data INAPROC menunjukkan penyedia dengan harga premium justru memiliki lebih banyak transaksi. Beberapa penyedia murah bahkan telah menerima Surat Peringatan dari LKPP. IDEAS menjamin kepatuhan dan kualitas. [5] |
| **"Kami butuh solusi cloud."** | IDEAS mendukung model deployment fleksibel: cloud, on-premise, atau hybrid, sesuai dengan kebutuhan dan regulasi data residency. |
| **"Kami ingin langsung implementasi AI/GenAI."** | AI/GenAI tanpa fondasi data yang kuat menghasilkan "garbage in, garbage out". IDEAS menawarkan pendekatan **AI-Ready Data Foundation**: (1) Data quality assessment, (2) AI governance (NIST AI RMF, ISO 42001), (3) Responsible AI principles. |
| **"Kami sudah pakai Data Mesh/Fabric."** | Bagus! IDEAS dapat membantu mengoptimalkan implementasi yang ada melalui: (1) Domain boundary assessment, (2) Federated governance operating model, (3) Standardisasi data contract (ODCS-compliant), (4) Optimalisasi self-serve platform. |

## Unique Selling Propositions (USPs)

1.  **Satu Ekosistem, Satu Vendor:** Solusi end-to-end dari advisory strategis, implementasi platform, hingga pemberdayaan sumber daya manusia.
2.  **Keahlian Regulasi Indonesia:** Pemahaman mendalam dan teruji pada SPBE, Satu Data Indonesia, UU PDP, dan peraturan pengadaan pemerintah (Perpres 46/2025).
3.  **Fondasi DAMA-DMBOK:** Menggunakan standar internasional yang diakui secara global sebagai dasar metodologi, bukan framework proprietary yang tertutup.
4.  **Model Fleksibel & Bertahap:** Implementasi modular yang dapat disesuaikan dengan anggaran dan tingkat kematangan klien.
5.  **Fokus pada Kemandirian Klien:** Tujuan akhir adalah memberdayakan tim internal klien melalui transfer pengetahuan dan sertifikasi, bukan menciptakan ketergantungan.

## Glossary of Terms

| Akronim / Istilah | Kepanjangan / Definisi |
| :--- | :--- |
| **AI RMF** | Artificial Intelligence Risk Management Framework. Kerangka kerja dari NIST untuk mengelola risiko terkait AI. |
| **BNSP** | Badan Nasional Sertifikasi Profesi. Lembaga yang berwenang melaksanakan sertifikasi kompetensi kerja di Indonesia. |
| **CDMP** | Certified Data Management Professional. Sertifikasi profesional dari DAMA International. |
| **DAMA-DMBOK** | Data Management Body of Knowledge. Kerangka kerja dan panduan praktik terbaik untuk manajemen data. |
| **DGO** | Data Governance Office. Fungsi atau unit organisasi yang bertanggung jawab atas tata kelola data. |
| **INAPROC** | Indonesia National Procurement. Sistem Pengadaan Secara Elektronik (SPSE) yang dikelola oleh LKPP. |
| **LKPP** | Lembaga Kebijakan Pengadaan Barang/Jasa Pemerintah. |
| **NIST** | National Institute of Standards and Technology. Lembaga standar teknologi di Amerika Serikat. |
| **ODCS** | Open Data Contract Standard. Standar untuk kontrak data yang dapat dibaca mesin. |
| **OPD** | Organisasi Perangkat Daerah. Satuan kerja pemerintah daerah di Indonesia. |
| **PMK** | Peraturan Menteri Keuangan. |
| **Perpres** | Peraturan Presiden. |
| **SBM** | Standar Biaya Masukan. Batas tertinggi biaya yang ditetapkan pemerintah untuk penyusunan anggaran. |
| **SDI** | Satu Data Indonesia. Kebijakan tata kelola data pemerintah untuk menghasilkan data yang akurat, mutakhir, dan terpadu. |
| **SPBE** | Sistem Pemerintahan Berbasis Elektronik. Penyelenggaraan pemerintahan yang memanfaatkan teknologi informasi dan komunikasi. |
| **UMKK** | Usaha Mikro, Kecil, dan Koperasi. |
| **UU PDP** | Undang-Undang Perlindungan Data Pribadi (UU No. 27 Tahun 2022). |
