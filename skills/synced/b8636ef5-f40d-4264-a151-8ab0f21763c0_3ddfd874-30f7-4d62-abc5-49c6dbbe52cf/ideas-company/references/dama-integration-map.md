# IDEAS Services & DAMA-DMBOK Integration Map

**Last Updated: February 2026**

This document provides a strategic mapping between the service offerings of PT IDEAS and the globally recognized DAMA-DMBOK2 framework, with forward-looking alignment to the **DAMA-DMBOK 3.0** project. The DAMA-DMBOK 3.0 project, initiated in June 2025, is a significant, community-driven undertaking to modernize the framework. It incorporates a **Triple Helix governance model** (Editorial Board, CDMP Masters Review Panel, Global Community) and introduces new topics such as **AI governance, cloud data management, and modern data platforms** [1]. Core drafting is occurring throughout 2026, with a planned publication target of Q2 2027. This map serves as a guide for leveraging the `dama-research` skill to enrich the practical application of the `ideas-company` skill.

### CDO Landscape Context (2026)

Understanding the Chief Data Officer landscape in 2026 informs how IDEAS positions its advisory services:
- **CDO Top Priority:** Data Governance (51% of CDOs cite this as #1)
- **CDO Team Growth:** 54% grew last year; 63% plan growth in next 12 months
- **CDOs Reporting to C-Suite:** 87% — indicating data management is now a board-level concern
- **Implication for IDEAS:** Position advisory services as supporting CDO-level strategic initiatives, not just operational data management.

## Core Principle of Collaboration

- **`dama-research` provides the *\"Why\"* and the *\"What\"*:** It offers the theoretical foundation, global best practices, standardized frameworks, and comprehensive knowledge from the DAMA-DMBOK2.
- **`ideas-company` provides the *\"How\"*:** It offers the contextualized service offerings, delivery methodologies, pricing models, local regulatory knowledge (SDI, SPBE, UU PDP), and real-world case studies (Ekosistem Data Jabar).

By combining both, we can deliver solutions that are both theoretically sound and practically implementable in the Indonesian context.

## Collaborative Workflow Example

**User Request:** \"Help me build a data governance function for my government agency.\"

1.  **Intent Recognition (`ideas-company`):** The agent identifies the intent as a complex request involving strategy, governance, and potentially training.
2.  **Initial Framing (`ideas-company`):** The agent consults its `services-catalog.md` and identifies the \"Advisory & Governance\" pillar as the starting point.
3.  **Maturity Assessment (`dama-research`):** The agent uses the `dama-research` skill's maturity assessment tools to propose a maturity assessment as the first logical step, explaining that this will identify key gaps based on the DAMA framework.
4.  **Service Recommendation (`ideas-company`):** Based on the assessment results (e.g., low scores in Data Quality and Metadata), the agent uses `ideas-company`'s `recommend_service.py` to recommend specific services like \"Data Governance & Compliance Framework\" and \"Data Quality Program\'.
5.  **Deliverable Mapping (`ideas-company`):** The agent consults `service-deliverables-map.md` to identify which DAMA deliverables are Must/Should/Could for the recommended services, with effort estimates per deliverable.
6.  **Deliverable Scaffolding (`dama-research`):** The agent pulls relevant templates from `dama-research/templates/deliverables/`, such as `KA-01/01-governance-charter.md`, `KA-11/01-data-quality-strategy.md`, and `KA-01/05-roles-responsibilities.md`.
7.  **Agile Planning (`ideas-company`):** The agent structures the work using `agile-work-hierarchy.md` — mapping the project into Initiatives, Epics (per service), Features (per phase), and User Stories (per task).
8.  **Proposal & Pricing (`ideas-company`):** The agent uses `generate_proposal.py` and `pricing_engine.py` to assemble a full proposal, populating it with the deliverables from `dama-research` and pricing the required team based on its internal rate card.
9.  **Final Delivery:** The agent presents a comprehensive proposal that is grounded in a global framework (DAMA), tailored to the client's specific needs (via the assessment), and includes a clear scope, deliverables, and cost (from IDEAS's offerings).
