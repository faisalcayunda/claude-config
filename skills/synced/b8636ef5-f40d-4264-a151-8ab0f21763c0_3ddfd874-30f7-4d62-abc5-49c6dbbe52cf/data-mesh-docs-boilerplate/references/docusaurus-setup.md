## Surge.sh Deployment

### Manual deploy
```bash
npm run build
npx surge build/ your-project.surge.sh
```

### Environment variable
```
SURGE_DOMAIN=your-project.surge.sh
SURGE_TOKEN=<token from `npx surge token`>
```

### CNAME file (custom domain)
```
# static/CNAME
your-project.surge.sh
```

### Protected deployment (surge.sh passcode)
Surge.sh supports basic protection via `--passcode`:
```bash
npx surge build/ your-project.surge.sh --passcode $SURGE_PASSCODE
```

> ⚠️ **Penting:** Surge.sh adalah public hosting. Untuk dokumen dengan klasifikasi
> `Restricted` atau `Confidential`, pertimbangkan self-hosted Docusaurus di balik
> reverse proxy dengan autentikasi, atau gunakan hanya Confluence/Google Drive.

## validate-frontmatter.js

```js
#!/usr/bin/env node
/**
 * Validates that all .md files under docs/ have required frontmatter fields.
 * Required: title, sidebar_label, phase, version, data_product_id, data_classification
 */
const fs = require('fs');
const path = require('path');
const { glob } = require('glob');
const matter = require('gray-matter');

const REQUIRED_FIELDS = [
  'title', 'sidebar_label', 'phase', 'version',
  'data_product_id', 'data_classification'
];
const VALID_PHASES = ['bootstrap', 'design', 'development', 'delivery', 'monitoring', 'eosl'];
const VALID_CLASSIFICATIONS = ['Public', 'Internal', 'Restricted', 'Confidential'];

let errors = 0;

const files = glob.sync('docs/**/*.md', { ignore: ['docs/intro.md'] });
files.forEach(file => {
  const content = fs.readFileSync(file, 'utf8');
  const { data } = matter(content);

  REQUIRED_FIELDS.forEach(field => {
    if (!data[field]) {
      console.error(`❌ ${file}: missing frontmatter field '${field}'`);
      errors++;
    }
  });

  if (data.phase && !VALID_PHASES.includes(data.phase)) {
    console.error(`❌ ${file}: invalid phase '${data.phase}'`);
    errors++;
  }

  if (data.data_classification && !VALID_CLASSIFICATIONS.includes(data.data_classification)) {
    console.error(`❌ ${file}: invalid data_classification '${data.data_classification}'`);
    errors++;
  }
});

if (errors > 0) {
  console.error(`\n💥 Frontmatter validation failed with ${errors} error(s).`);
  process.exit(1);
} else {
  console.log(`✅ All ${files.length} files passed frontmatter validation.`);
}
```
