# AI detectors

Read only when the user says the text will be run through an AI detector (academic paper, client submission). The writing rules in `SKILL.md` and the language references already remove the tells detectors key on; this file adds only what changes when a detector is in the loop.

## What detectors measure

Turnitin, GPTZero, Originality.ai and Copyleaks score two things the writing rules already address: how predictable the word choices are, and how much sentence length and structure vary across a paragraph. Turnitin also reads rhythm and predictability across whole paragraphs, not sentence by sentence, so every paragraph needs a different pattern from the one before it: different length, sentence count and shape. Run the long-form checklist in the language reference with that in mind.

## Language coverage

As of April 2026 Turnitin does not support AI detection for Indonesian. It covers English and a limited set of European languages. Indonesian text can still be checked by multi-language detectors (GPTZero, Originality.ai, Copyleaks), and Turnitin's language list grows, so the Indonesian rules still matter for submitted work.

## Humanizer tools

Turnitin (since August 2025) detects text processed by paraphrase and humanizer tools, trained on the outputs of several of them, and marks it more severely than plain AI text. Do not run a draft through such a tool. Write correctly from the start with this skill.

## Grammar tools

Heavy use of grammar correction tools (Grammarly, ProWritingAid) can flatten natural variation and trigger false positives. Keep the register's natural variation: a fragment where the register allows it, an uneven paragraph, a colloquial connector. Never introduce errors on purpose.

## What does not help

Absence of legacy vocabulary (delve, tapestry) or of em dashes proves nothing to a detector; current models already avoid them. Mechanical alternation of short and long sentences is itself a fingerprint. The structural rules (cadence, openers, paragraph rhythm, no four-part arc) are what move the score.
